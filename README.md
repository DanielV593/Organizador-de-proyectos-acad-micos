# Ninja Tournament Simulator (GUI)

## Descripción
Sistema de torneo de combates simulados desarrollado en Python. Implementa una interfaz gráfica de usuario y utiliza algoritmos avanzados para la gestión de participantes y clasificaciones.

## Tecnologías Utilizadas
* **Lenguaje:** Python
* **Interfaz Gráfica:** Tkinter

## Características Clave
* Implementación de estructuras de datos complejas: **Árboles binarios, colas**.
* Algoritmos de ordenamiento para el sistema de rankings.
* Registro de usuarios y persistencia de datos.

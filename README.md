# Academic Project Manager

## Descripción
Aplicación desarrollada en C/C++ diseñada para gestionar, categorizar y organizar proyectos académicos. Utiliza compilación multiplataforma y gestión eficiente de memoria.

## Tecnologías Utilizadas
* **Lenguaje:** C / C++
* **Construcción y Compilación:** CMake

## Características Clave
* Gestión eficiente de estructuras de datos en memoria.
* Configuración modular mediante CMake.
* Arquitectura orientada a la optimización de recursos.
